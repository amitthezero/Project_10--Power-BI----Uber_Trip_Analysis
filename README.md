# UBER TRIP ANALYSIS | POWER BI

## Project Overview

Interactive **Uber Trip Analysis Dashboard** built in **Power BI** to analyze booking trends, revenue, trip distance, trip duration, vehicle performance, and location patterns.

## Business Questions

- How many trips were booked and what revenue was generated?
- When are the **peak and off-peak** booking periods?
- Which days and hours have the highest trip demand?
- Which vehicle types generate the most bookings and revenue?
- Which pickup and drop-off locations are most frequently used?
- What are the longest and shortest trips?
- How can trip patterns support **pricing, driver allocation, and operational planning**?

## Key KPIs

- **103.7K** Total Bookings
- **$1.55M** Total Booking Value
- **$14.98** Average Booking Value
- **349K Miles** Total Trip Distance
- **3.4 Miles** Average Trip Distance
- **16 Min** Average Trip Time

## Dashboard Pages

### **1. Overview Analysis**
Analyzes bookings, revenue, trip distance, payment type, day/night shifts, vehicle performance, and top pickup locations.

### **2. Time Analysis**
Analyzes trip demand by **pickup time, day of week, and hour-day combinations** to identify peak demand periods.

### **3. Details**
Provides a detailed trip-level data table for granular analysis and exploration.
